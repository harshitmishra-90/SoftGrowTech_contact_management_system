# 📒 Contact Management System (Java Console Application)

A simple menu-driven console application built in Java to manage contacts.  
This project demonstrates core concepts of **Object-Oriented Programming (OOP)**, **ArrayList usage**, and **input validation**.

---

## 🚀 Features
- **Add Contact**  
  - Accepts full names (with spaces).  
  - Validates phone numbers (must be 10 digits, starting with 6–9).  
- **Show All Contacts**  
  - Displays all saved contacts in a clean format.  
- **Search Contact by Name**  
  - Case-insensitive search.  
  - Displays contact details if found.  
- **Delete Contact by Name**  
  - Removes a contact from the list.  
  - Confirms deletion or shows "Contact not found".  
- **Exit Program**  
  - Gracefully terminates the application.

---

## 🛠️ Technologies Used
- **Java SE** (Core Java)
- **ArrayList** for dynamic storage
- **Scanner** for user input
- **Regex** for phone number validation
